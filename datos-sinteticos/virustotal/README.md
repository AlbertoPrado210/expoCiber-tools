# Respaldos sanitizados de VirusTotal

Esta carpeta recibirá los últimos resultados obtenidos durante los ensayos.

Los archivos JSON guardan únicamente estadísticas, nombres de motores, etiquetas públicas, fechas e indicadores desactivados. No guardan la API key ni una URL activa.

El modo `auto` del script actualiza el respaldo cuando la consulta en vivo funciona y lo reutiliza cuando no existe conexión o se alcanza la cuota.
