# Seguridad y privacidad

Este repositorio no debe contener API keys, contraseñas, correos personales ni indicadores privados.

Si encuentras una credencial real publicada:

1. Revoca o rota la credencial de inmediato.
2. Informa al propietario mediante un canal privado.
3. Evita copiar el secreto en un issue público.
4. Limpia el historial únicamente después de invalidar la credencial.

Las cuentas de `hibp-integration-tests.com` y la clave de prueba compuesta por ceros pertenecen al mecanismo oficial de integración de Have I Been Pwned. No representan una credencial personal.
